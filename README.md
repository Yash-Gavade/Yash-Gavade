## 🚀 Featured Projects

### 1. ReasonShift — LLM Answer Consistency & Robustness

**Python · Hugging Face · LLM Evaluation · Statistical Analysis**

Investigating whether semantically equivalent questions produce consistent answers across different language models.

- Evaluated **3 open-weight LLMs** across **360 model inputs**.
- Studied linguistic transformations and their impact on answer consistency.
- Measured accuracy, flip rate, and robust accuracy.
- Applied statistical evaluation to investigate model behavior.

🔗 **[View ReasonShift on GitHub](https://github.com/Yash-Gavade/ReasonShift)**

### 2. FaithfulLLM — Evaluating LLM Self-Explanations

**Python · PyTorch · Transformers · Explainable AI**

An empirical evaluation of whether LLM-generated explanations genuinely support their predicted answers.

- Evaluated **3 open-weight models** using **900 model inputs**.
- Used GSM8K, CommonsenseQA, and StrategyQA datasets.
- Investigated answer correctness and explanation-support faithfulness.
- Analyzed differences in model reliability and explanation quality.

🔗 **[View FaithfulLLM on GitHub](https://github.com/Yash-Gavade/FaithfulLLM)**

### 3. LuxNLP — Luxembourgish Named Entity Recognition

**XLM-RoBERTa · Multilingual NLP · NER · RAG**

A multilingual information extraction project focused on identifying named entities in Luxembourgish text.

- Developed a named entity recognition workflow using XLM-RoBERTa.
- Worked with a corpus containing **41,723 sentences**.
- Evaluated entity extraction across multiple categories.
- Achieved **0.8216 test F1-score** with the XLM-R model.

🔗 **[View LuxNLP on GitHub](https://github.com/Yash-Gavade/LuxNLP)**

### 4. CommerceIQ 360 — Enterprise AI Analytics Platform

**Python · SQL · PostgreSQL · Power BI · FastAPI · Docker**

An end-to-end data analytics and AI-assisted business intelligence platform.

- Built SQL-based data processing and analytical models.
- Developed **6 interactive Power BI dashboards**.
- Implemented customer, revenue, product, and operational analytics.
- Integrated FastAPI, Streamlit, PostgreSQL, and Docker.
- Developed an AI-assisted KPI interpretation workflow.
- Worked on testing, system reliability, and production-oriented deployment.

**Focus:** Data engineering, business intelligence, API development, and applied AI.
